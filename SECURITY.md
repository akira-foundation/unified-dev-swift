# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities by email to
[unified@akira-io.com](mailto:unified@akira-io.com). Do not open a public issue.

We will confirm receipt within 72 hours and will provide a more detailed response within 7 days
indicating the next steps.

## Disclosure policy

We follow coordinated disclosure. After a fix is released, we will publish a security advisory on
GitHub with credit to the reporter (unless they prefer to remain anonymous).

## Supported versions

| Version | Status |
|---------|--------|
| Latest  | Supported |
| Older   | Best-effort backports for critical issues |
